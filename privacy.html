隱私權政策

賽爾號資訊站（以下簡稱「本站」）為個人開發、維護的非官方《賽爾號》玩家資訊工具，網站網址為 https://seerinfo.app/。

本站重視資料透明度。以下依照網站目前提供的功能，說明可能處理的資訊及其用途；各項功能實際處理的資料會依使用情況而有所不同。

01 適用範圍

本政策適用於本站的圖鑑、屬性克制、模擬培養、投票與管理、帳號及台服玩家資料查詢等功能。

經由本站連結至第三方網站或平台時，對方可能另有其資料處理方式與隱私權政策。

02 蒐集及使用的資訊

一般瀏覽、圖鑑與模擬培養

瀏覽圖鑑、查詢屬性克制及使用模擬培養功能，原則上不需要註冊帳號或主動提供姓名、電子郵件等個人身分資料。模擬培養的分享網址可能包含使用者自行設定的配置內容；分享前請確認連結中的資訊適合公開。

既有帳號、投票及管理功能

本站使用 Supabase 提供帳號驗證及資料庫服務。網站目前暫停對一般訪客開放登入與新帳號註冊，但既有帳號及管理功能仍可能處理以下資料：

  • 電子郵件地址、帳號識別碼與登入狀態。
  • 使用者自行綁定的米米號或遊戲帳號識別資訊。
  • 投票選擇、投票紀錄及維護權限所需的操作資料。

上述資料用於身分驗證、投票與管理功能、避免重複投票，以及必要的服務維護。

台服玩家資料查詢

使用者輸入米米號後，本站會透過部署於 Microsoft Azure 的後端服務向遊戲伺服器請求資料，並依功能顯示玩家暱稱、在線狀態、部分競技統計及出戰／待戰精靈等遊戲資訊。

本站不提供個別使用者的查詢歷史檢視功能，也不以建立可供一般訪客查閱的查詢紀錄為目的。後端主機或相關服務仍可能為連線、安全、故障排除產生技術性日誌；不應將上述說明解讀為完全不產生任何日誌。

必要的技術性資訊

網站託管、資料庫及後端供應商在提供服務時，可能處理 IP 位址、瀏覽器與裝置資訊、請求時間、連線狀態及錯誤紀錄等技術性資料，用於傳輸請求、維持服務及資訊安全。

03 Cookie 與瀏覽器儲存

本站部分功能可能使用瀏覽器 Local Storage、Cookie 或其他必要儲存技術。例如既有帳號的登入驗證服務可能在瀏覽器保存工作階段資訊。

你可透過瀏覽器設定管理或清除儲存資料，但清除後可能需要重新登入，或重新設定部分功能。

04 第三方服務

本站依功能使用或載入以下第三方服務與內容：

  • GitHub Pages：網站靜態內容託管。
  • Supabase：帳號驗證、投票及管理資料庫。
  • Microsoft Azure：台服玩家查詢後端服務。
  • SeerAPI、遊戲官方及相關資料來源：圖鑑、遊戲資訊、圖片或其他資源。
  • 第三方 CDN：提供本站所需的部分程式函式庫。

當瀏覽器連線至上述第三方服務時，可能直接向該服務傳送網路請求及相關技術性資訊。實際資料處理地點可能依服務商的設定與基礎設施而異。

本站不會以販售使用者個人資料為目的而主動提供資料予第三方；為提供功能而使用的服務商，則依各自政策及相關約定處理必要資料。

05 資料保存及安全

帳號、投票及相關資料的保存期間，取決於功能是否仍需使用、系統設定、必要的維運需求及適用法令。第三方基礎設施所產生的技術性日誌亦可能依其設定保留一段期間。

本站會採取合理的權限控管及安全措施，降低未經授權的存取風險；但任何網路服務都無法保證絕對安全。

若想了解特定資料是否仍保存，或申請刪除本站實際持有的資料，請透過下方聯絡方式提出請求。

06 使用者權利與資料請求

如對本站所持有的個人資料有疑問，可依適用法令提出查詢、閱覽、複製、更正、停止利用或刪除等請求。為避免他人冒名申請，本站可能需要合理確認申請人的身分或資料關聯性。

如認為台服玩家資料查詢功能涉及隱私問題，也可聯絡站長說明情況。本站將依實際可控制的資料範圍及適用法令評估處理；本站無法直接修改或刪除遊戲官方伺服器保存的資料。

提出資料請求時，請勿傳送密碼、完整登入憑證或其他不必要的敏感資訊。

07 政策更新

本站可能因功能、第三方服務、資料處理方式或法規變更而修訂本政策。更新後會公布於本頁，並標示最新更新日期。

08 聯絡方式

若有隱私、資料刪除或其他相關問題，可透過 Discord 私訊站長 @zerof0512，也可前往「關於本站」頁面查看聯絡方式。

透過 Discord 傳送的訊息同時受 Discord 自身的隱私權政策規範。
