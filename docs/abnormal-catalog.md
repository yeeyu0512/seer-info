# 異常狀態圖鑑

入口：`?tab=abnormal`，分享詳情：`?tab=abnormal&abnormal=43`（漸凍）。沿用單頁導航，部署於 GitHub Pages 子路徑也可使用。`abnormal` 是專用參數，與其他圖鑑的 `id`、培養的 `build`、競技池的 `server` 分開。

## 維護資料

功能名稱統一使用 `abnormal`：資料檔 `data/abnormal.json`、清單欄位 `abnormals`、模組 `js/seer-abnormal.js`、導航 `tab=abnormal` 與分享參數 `abnormal`。單筆資料仍沿用原先約定的 `relatedStatuses`、`verificationStatus` 欄位名稱。

全站搜尋的「全部分類」與「異常狀態」皆會查詢這份靜態 JSON，支援繁簡名稱、效果關鍵字及數字 ID（含 0）。每次最多列出 4 筆，結果連結直接開啟對應的異常詳情。

玩家介面以效果與轉化為主，不顯示資料說明區塊。來源、核對日期、素材說明與完整待確認項目僅保留在 JSON 與本維護文件。未確認的狀態效果仍在卡片標示；轉化區不顯示提前解除的待確認提示。

圖鑑依編號由大到小排列，每頁展示 12 種，搜尋或切換分類會回到第一頁並維持降冪排序；分頁不影響分享網址與跨頁的詳情關聯。全站搜尋仍優先顯示完全同名的結果，其餘異常結果依編號降冪排列。「特殊」標籤以紅色緩慢閃爍呈現，系統設定減少動態效果時停用動畫；限制與衍化標籤維持原有樣式。

編輯 `data/abnormal.json` 的 `abnormals` 即可新增項目。`id` 統一使用使用者提供表格的非負整數編號，並依編號排序；不保留英文 ID 或英文網址別名。所有 `targetId`、`relatedStatuses` 也使用數字，不可使用陣列索引推算 ID。麻痺為 0、冰封為 15、漸凍為 43；0 是有效 ID，不能用真假值判斷是否存在。

目前收錄完整的 0～44 共 45 種。依使用者指定，3 寄生對手、12 山神守護、17 神話、18 免疫歸入「其他」，21 異常免疫歸入「附屬」並帶有「特殊」標籤。「其他」是本站的展示分類，不代表遊戲官方的主要分類名稱；「特殊」僅顯示在卡片與詳情，不提供獨立篩選按鈕。編號來源是使用者提供的表格，並非另行核實的官方編碼規格。表中漸凍轉化為 2 回合冰封，與先前 BWIKI 記載的 3 回合不同，效果差異留待後續核實。

- `category`：控制、弱化、附屬、其他擇一。
- `tags`：可重疊的限制、衍化、特殊標籤；依來源或使用者指定標記，不因有轉化效果就自行認定為衍化類。「特殊」不加入 `ABNORMAL_FILTERS`。
- `summary`、`description`、`effects`：卡片摘要、完整描述及補充判定。未知效果填「待確認」，不要猜測。
- `removalConditions`：已核實的解除條件；未核實時留空陣列，並在 `verificationNotes` 說明待確認事項。
- `transformations`：每項為 `{ targetId, condition, duration, note }`。`duration` 僅記錄該轉化產生狀態的回合數，未知時填 `null`。多個分支須在 `note` 說明是否隨機擇一。轉化圖會依資料遞迴顯示，並防止循環。
- `relatedStatuses`：相關項目的 ID 陣列，建議雙向連結。
- `sources`：每項為 `{ title, url, checkedAt, scope }`；保留 HTTPS 原始來源及核對日期。使用者提供的表格使用 `type: "userProvided"`、`url: null`，不虛構公開來源網址。
- `verificationStatus`：`pending`（待確認）、`coreVerified`（核心機制已核對，仍有未確認項）、`verified`（已核對）。不要把公開資料核對當成遊戲實測。
- `verificationNotes`：解除、提前清除與結算等仍待確認的細節。
- `icon`：使用使用者提供的 `./assets/icons/abnormal/{id}.png`，檔名對應異常狀態編號。0～44 共 45 種收錄項目均已連接對應 PNG 圖示。

持續回合數通常來自技能或來源效果；不能把「漸凍轉成 3 回合冰封」解讀成冰封固定持續 3 回合，也不能把魘昧的最多 5 回合寫成固定 5 回合。

## 查證範圍

2026-11-02 依 [BWIKI 對戰機制・異常狀態附加效果](https://wiki.biligame.com/seer/对战机制#异常状态附加效果) 核對原先 40 項的主要分類及核心效果。頁面表格的凍傷與中毒共用效果欄，疲憊、害怕、石化與麻痺共用效果欄。新增的 3、12、17、18、21 號依使用者提供的完整表格整理效果，並依使用者指定分類，未另作公開資料核實。`coreVerified` 表示核心內容與所記錄來源核對，不等於遊戲內實測或所有來源皆經獨立公開核實。

該表未完整交代各狀態被技能、魂印、主動切換等提前解除的判定，也未釐清所有「結束後」轉化在提前解除時的行為，因此保留為待確認。未採用其他版本（含啟航）的機制，也尚未完成逐項遊戲實測。

## 驗證

執行 `npm test` 與 `npm run check`。`tests/abnormal.test.mjs` 檢查候選完整性、唯一 ID、關聯、圖示、搜尋、重疊篩選與轉化資料；導航回歸測試涵蓋原有圖鑑及獨立狀態參數。

沿用站台原有的 head 與 sitemap。圖鑑切換和詳情開關不改寫頁面標題或 metadata；分享連結僅透過既有查詢參數導航開啟對應內容。
