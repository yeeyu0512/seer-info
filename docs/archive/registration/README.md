# 註冊功能封存片段

此處保留從首頁及登入模組移出的註冊相關內容，供未來重新設計時參考。

| 檔案 | 內容 |
| --- | --- |
| `registration.html.txt` | 確認密碼、米米號欄位、建立帳號按鈕、模式切換與原提示文字 |
| `registration.css.txt` | 註冊按鈕、切換入口與提示文字樣式 |
| `registration-errors.js.txt` | 註冊專用錯誤訊息與原共用錯誤回傳片段 |

檔案均使用 `.txt` 副檔名，未被 HTML、CSS 或 JavaScript 引用，不會載入或執行，也不提供可開啟的註冊頁面。封存前程式已無註冊 API 呼叫，因此這裡不是可直接啟用的完整註冊流程。

目前站務登入仍由 `js/account/auth-view.js` 與 `js/auth.js` 處理。若未來恢復註冊，需另行實作、檢查後端設定並驗證，不能只還原這些片段。
